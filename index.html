Formação Crítica & Cidadania Digital

Pesquisa Histórica e Uso Ético da Inteligência Artificial

A tecnologia não é neutra. Construir este projeto exige rigor histórico para não reproduzir vieses algorítmicos nem inventar dados.

1. Combate ao Apagamento Epistemológico

Durante séculos, barreiras raciais e jurídicas dificultaram o registro de patentes por pessoas negras — muitas vezes obrigadas a ceder direitos a empregadores ou ocultar sua identidade.

  • Fontes Primárias: Sempre consulte registros oficiais como o USPTO (Escritório de Patentes dos EUA) e o INPI (Brasil).
  • Protagonismo Brasileiro: Nomes como André Rebouças e Enedina Alves Marques provam que a engenharia negra também construiu a infraestrutura do Brasil.

2. Uso Crítico e Transparente de IA no Código

Ferramentas de IA generativa aceleram a escrita de HTML, CSS e JavaScript, mas podem gerar "alucinações" (datas erradas, números de patentes falsos ou biografias misturadas).

  • Curadoria Humana: Todo dado histórico gerado por IA deve ser validado em enciclopédias acadêmicas antes da publicação.
  • Auditoria de Acessibilidade: O desenvolvedor deve testar a navegação por teclado e o contraste de cores, garantindo inclusão real.
Publicação na Web

Como Publicar Este Projeto no GitHub Pages

Siga estes passos para colocar seu museu virtual no ar gratuitamente e compartilhar o link público com sua turma ou comunidade.

  1. Passo 01

    Organize os Arquivos

    Salve os 3 arquivos na mesma pasta: index.html, style.css e script.js.

  2. Passo 02

    Envie para o GitHub

    Crie um repositório público no GitHub e envie os arquivos pelo site ou via terminal Git:

    git init
git add .
git commit -m "Publica Museu Virtual"
git branch -M main
git remote add origin SEU_LINK.git
git push -u origin main
  3. Passo 03

    Ative o GitHub Pages

    No repositório, acesse Settings > Pages. Em Branch, selecione main e clique em Save. Em 1 minuto seu site estará online!
